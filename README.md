# 🛒 贴心购 - AI购物伴侣

一个面向用户的购物场景 AI 助手微信小程序产品设计。

## 📋 产品定位

**贴心购** 是用户的私人购物管家，具备类似 OpenClaw 的 Memory、Soul 等机制，能够成为用户最贴心的购物助理，帮助用户完成生活中所有的购物需求。

**核心价值**：「记住你的每个需求，主动提醒每个时机」

## ✨ 核心功能

- 🧠 **记忆系统 (Memory)** - 用户档案、家人档案、购物历史、囤货追踪
- ❤️ **人格系统 (Soul)** - 贴心管家风格，有个性、懂分寸、主动关怀
- 🔔 **主动服务** - 重要日期提醒、补货提醒、价格监控
- 🛍️ **商城对接** - 商品搜索、直接下单、订单追踪

## 🎯 目标用户

| 用户类型 | 核心痛点 |
|---------|---------|
| 忙碌白领 | 想买东西但总忘、不知买啥好 |
| 家庭主妇/主夫 | 家人需求多，容易遗漏 |
| 送礼困难户 | 不知买什么礼物、总错过日期 |
| 囤货党 | 不知何时补货、错过好价 |

## 🔑 关键交互场景

### Case 1: 老婆生日礼物提醒
- 前7天：温柔提醒"礼物准备了吗？"
- 前3天：推荐礼物选项
- 前1天：确认礼物状态

### Case 2: 牛奶补货提醒
- 记录购买周期
- 预估消费速度
- 提前3天提醒补货

### Case 3: 用户告知信息
- 对话中自然透露家人生日
- AI主动询问并记录
- 形成完整的家人档案

### Case 4: 价格监控
- 用户浏览商品自动关注
- 检测价格变动
- 降价时主动通知
