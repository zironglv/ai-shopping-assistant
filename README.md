# 贴心购 - AI购物伴侣

> 让你不再操心购物，我只为你着想

## 📖 项目简介

「贴心购」是一个微信小程序产品设计方案，定位为用户的私人购物管家。基于类似 OpenClaw 的 Memory 和 Soul 机制，能够主动理解用户、记录重要信息、并在关键时刻提供贴心服务。

## 🎯 核心特性

- **🧠 Memory 记忆系统** - 记录用户档案、家人信息、购物历史、补货追踪
- **💝 Soul 人格机制** - 温暖贴心的人格设定，个性化服务风格
- **🔔 主动服务** - 生日提醒、补货提醒、优惠通知
- **🛒 商城对接** - 直接购买所需商品

## 📋 核心用户场景

### Case 1: 生日礼物提醒
用户告诉 AI "老婆生日是 6月15号"，AI 自动记录并提前提醒买礼物，推荐合适商品。

### Case 2: 补货提醒
AI 根据用户购买频率，智能预测"牛奶快喝完了"，主动提醒补货。

### Case 3: 优惠通知
用户关注商品降价时，AI 主动推送优惠信息。
